# Surrey County XC Championships results, 1961/62 to 2012/13

Downloaded 17 Oct 2026 from https://www.surreyathletics.uk/crosscountry/champs/ (every race and age group listed for each year).
`results.jsonl` has one line per finisher: `y` = the season's first year (y 1985 = the January 1986 champs, i.e. 1985/86),
`cat` = race (SM senior men, JM junior men, SW senior women, M40 etc.), `p` = position, `n` = name as printed, `club`, `t` = time.

Use it to turn initials into full names: the champs often print the full first name with the club. Match on surname + club
(and initial), within a few seasons of the League result. Some years print initials only; some runners appear as both.
Every year 1961/62-2012/13 is present (about 32,000 finishers).
